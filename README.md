# Story Nest

**Bedtime, made easy.** A bring‑your‑own‑key AI bedtime‑story maker where your child is the hero.

- 🌙 **Tonight's story** — pick a child, theme (calm, brave, dinosaurs, space…), length (3/5/8 min) and a special request ("include her cat Biscuit").
- 📖 **Read mode** — one page at a time in big, calm text with a wavy progress bar; ends with a gentle thought and 2–3 "talk about it" questions.
- 🔁 **Sequels** — continue any story with a new self‑contained plot.
- ❤️ **Library** — favourites, read counts, multiple children, any language.
- Age‑appropriate rules built in: no scary villains for under‑6s, calm endings, no brands.

BYOK: Claude (Anthropic) or any OpenAI‑compatible endpoint. See [PRIVACY.md](PRIVACY.md).
